安裝 ComfyUI

若 /content/ComfyUI 已存在就跳過 Git clone；安裝 ComfyUI 基礎相依。

Colab · install.py
import subprocess, sys
from pathlib import Path
COMFY = Path('/content/ComfyUI')
if not (COMFY / 'main.py').exists():
    subprocess.run(['git', 'clone', 'https://github.com/Comfy-Org/ComfyUI.git', str(COMFY)], check=True)
else:
    print('ComfyUI already exists. Skipping clone.')
subprocess.run([sys.executable, '-m', 'pip', 'install', '-r', str(COMFY / 'requirements.txt')], check=True)
for name in ['diffusion_models', 'text_encoders', 'vae', 'loras', 'embeddings']:
    (COMFY / 'models' / name).mkdir(parents=True, exist_ok=True)
print('ComfyUI ready:', COMFY)

下載 H3 所需的五個檔案

包含 INT8 FL2VA、文字編碼器、INT8 Video VAE、Audio VAE、8-step Turbo LoRA。若檔案已存在會跳過。

Colab · download.py
from pathlib import Path
from huggingface_hub import hf_hub_download, list_repo_files
REPO = 'Comfy-Org/MiniMax-H3'
BASE = Path('/content/ComfyUI/models')
# The four core files plus two workflow-specific files observed in the H3 I2V template.
FILES = [
    'diffusion_models/minimax_h3_fl2va_pruned_int8_convrot.safetensors',
    'text_encoders/qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors',
    'vae/minimax_h3_video_vae_int8_convrot.safetensors',
    'vae/minimax_h3_audio_vae_fp32.safetensors',
    'loras/minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16.safetensors',
]
remote_files = set(list_repo_files(REPO))
missing_on_hub = [p for p in FILES if p not in remote_files]
if missing_on_hub:
    raise RuntimeError('Names not found in upstream repo: '+', '.join(missing_on_hub))
for name in FILES:
    path = BASE / name
    if path.exists() and path.stat().st_size > 0:
        print('Exists (skipping):', name)
        continue
    print('Downloading:', name)
    out = hf_hub_download(repo_id=REPO, filename=name, local_dir=str(BASE))
    print('Saved:', out)
print('Required model downloads finished.')

06

啟動雲端 ComfyUI

僅綁定 127.0.0.1:8188，不用公開隧道。

Colab · launch.py
# Start a private ComfyUI server inside Colab. No public tunnel.
import subprocess, sys, time
from pathlib import Path
from urllib.request import urlopen
COMFY='/content/ComfyUI'
LOG='/content/comfyui.log'
def alive():
    try:
        with urlopen('http://127.0.0.1:8188/system_stats', timeout=3) as r:
            return r.status == 200
    except Exception:
        return False
if not alive():
    with open(LOG,'a') as f:
        proc=subprocess.Popen([sys.executable,'main.py','--listen','127.0.0.1','--port','8188','--disable-pinned-memory'],cwd=COMFY,stdout=f,stderr=subprocess.STDOUT,start_new_session=True)
    print('Started PID:',proc.pid)
for _ in range(90):
    if alive():
        print('ComfyUI OK: http://127.0.0.1:8188')
        break
    time.sleep(2)
else:
    print('ComfyUI failed to start. Recent logs:')
    print(Path(LOG).read_text(errors='replace')[-5000:])

② ComfyUI 操作教學

開啟 ComfyUI 後：工作流程 → 瀏覽模板 → 影片 → MiniMax H3：圖生影片（Image to Video / I2V）。不要選 API 版本，因為你已下載權重。

換成自己的動漫人物

在範例藍色滑鼠的 Load Image / 載入圖片 節點，點圖片上方的檔名或上傳欄位，選 PNG/JPG。圖片會上傳到 Colab，並接到右邊的 first_frame。

改寫動畫提示詞

右邊 Image to Video (MiniMax H3) 節點內有大片英文文字框（原本從 Editorial tech product film... 開頭）。點文字框 → Ctrl + A → 貼上自己的 Prompt。

設定日語與聲音

Prompt 明確寫 speaks ONLY Japanese 並放日文引號台詞。H3 可生成影音，但口型與專業術語不保證完全精準，請人工複聽。

設定時間與比例

duration 在 Prompt 正下方，原本 5.0。解析度選擇器（Resolution Selector）可改 16:9；模板預設可能是 1:1、0.40 MP。

按下執行之後

右上角藍色「執行」→ 排隊中 → SamplerCustomAdvanced → 影片解碼 → 輸出。左側「資源」在生成前顯示沒有已生成檔案是正常的。輸出通常在 /content/ComfyUI/output/。

可以在 Colab 執行 !nvidia-smi 查看 GPU VRAM 與利用率。不要重複點執行，以免累積多個任務。

日文課程對話

日文發音、口型、固定鏡頭；動漫女忍者以角色圖片為基準。

④ 備份與下次重新啟動

只關閉 ComfyUI 網頁時，Colab 可能還在運作；但 Colab 執行階段一旦回收，/content 的模型、輸入圖與影片可能全部消失。先備份重要成品。

備份 output 影片到 Google Drive

save.py
# Mount Google Drive; the Drive folder consumes Drive quota, not local Windows disk.
from google.colab import drive
drive.mount('/content/drive')
from pathlib import Path
import shutil
SOURCE=Path('/content/ComfyUI/output')
TARGET=Path('/content/drive/MyDrive/MiniMax_H3/videos')
TARGET.mkdir(parents=True, exist_ok=True)
copied=0
for p in SOURCE.rglob('*'):
    if not p.is_file():
        continue
    dest=TARGET / p.relative_to(SOURCE)
    dest.parent.mkdir(parents=True,exist_ok=True)
    shutil.copy2(p,dest)
    copied+=1
print('Backed up',copied,'output files to',TARGET)

⑤ 疑難排解

HTTP 403：無法開啟 8188-...colab.dev

Colab proxy 代理存取拒絕，不代表 H3 安裝失敗。先確認伺服器在 127.0.0.1:8188 回應，優先使用上面的 serve_kernel_port_as_iframe(8188,height=900)。確認登入同一個 Google 帳戶，瀏覽器允許必要 Cookie；不要隨便公開 ComfyUI 8188 埠。

huggingface_hub 2.x 與 diffusers、gradio 等衝突

本次你曾見到 2.4.0 相依性警告。筆記中使用 huggingface_hub>=0.34,<2 避免類似問題。若之前安裝過 2.x，在新的儲存格跑：%pip install --force-reinstall --no-deps 'huggingface_hub==1.5.0'，然後 %pip check。具體仍應依當前 Colab 與 ComfyUI 相依版本調整。

pip check：IPython requires jedi

在 Colab 執行 %pip install jedi，再執行 %pip check。

HF_TOKEN does not exist

公開倉庫通常不需要 Token；只要下載完成即可忽略。若遇下載速度限制或授權要求，再安全地透過 Colab Secrets 提供 Token，勿放進公開頁面。

ComfyUI 仍顯示「缺少的模型」

使用上面的「確認模型位置與大小」程式碼，檢查所有資料夾與檔名。右側「缺少的模型」旁按 ↻；必要時重新整理網頁，或只停止並重啟 ComfyUI Python 服務。不要誤按瀏覽器直接下載導致 .safetensors 存到 Windows。

模型下載到 Windows，本地磁碟被占用

瀏覽器的「下載」按鈕有時是下載連結，不是後端安裝器。只用 Colab 的 hf_hub_download(...,local_dir='/content/ComfyUI/models') 會在雲端下載。Chrome 下載管理可以取消誤下載的檔案。

ComfyUI 的「安裝應用程式」提示

那是 Chrome PWA 網頁捷徑，不是 H3 主程式。可以直接取消。ComfyUI 仍執行在 Colab。

Out of memory / GPU 使用率低 / 畫面比例扭曲

先將解析度調回 0.4 MP、縮短 5 秒、batch 1。H3 多模型可能需 CPU offloading；A100 80GB 也不是永遠不會 OOM。輸入圖片盡量與輸出畫布比例相同。GPU-Util 低時可能是在載入權重、CPU 或磁碟等待，不等於運算壞掉。

⑥ 把筆記發布成可隨時查看的網頁

目前這份筆記是已完成的單檔 HTML 網頁，可以直接在 Windows 雙擊瀏覽，也可以上傳靜態主機。因尚未指定你的網站／GitHub 儲存庫，這份檔案尚未發布到公開網址。

選項 A：GitHub Pages（簡單）

  1. 登入 GitHub → New repository，名稱可用 minimax-h3-guide。
  2. 上傳本頁的 HTML 並更名為 index.html，Commit。
  3. Settings → Pages → Deploy from a branch → main / root → Save。
  4. 部署完成後到 https://你的帳號.github.io/minimax-h3-guide/ 查看。

公開 Repository／Pages 通常任何取得網址者都能閱讀，不要放憑證、私人素材、API Key。

選項 B：Firebase Hosting（沿用你的環境）

  1. 電腦安裝 Node.js 與 Firebase CLI，登入 firebase login。
  2. 建一個資料夾 public/，把本頁改名 public/index.html。
  3. 執行 firebase init hosting，選對 Firebase 專案，public 目錄設 public、不覆蓋 index。
  4. 執行 firebase deploy --only hosting，即可取得官方提供的網站網址。

這是純靜態教學網頁，不會啟動 Colab GPU 或託管影片生成服務；生成影片仍需在 Colab 執行。
